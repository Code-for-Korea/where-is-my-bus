# 지역 CSV 준비 스크립트

한국 법정구역(시도 > 시군구 > 읍면동 > 리)을 Rails 지역 적재용 CSV로 바꾼다. 법정동코드 CSV에서 계층과 이름을, VWorld 법정구역 SHP에서 지도 범위(bbox)를 만든다. 이 폴더에는 스크립트와 테스트만 두고, **데이터 파일(원본 CSV, SHP, 생성된 CSV)은 커밋하지 않는다.**

## 데이터 출처와 라이선스

| 데이터 | 용도 | 비고 |
|---|---|---|
| 국토교통부 법정동코드 CSV (EUC-KR, `법정동코드,법정동명,폐지여부`) | 계층, 이름 | `존재` 행만 사용 |
| VWorld 법정구역정보 시군구(SIG)·읍면동(EMD)·리(LIO) SHP (EPSG:5186) | bbox | CC BY, 출처 표시 필요. `A1` = 코드, `A2` = 이름 |

## 준비

```
pip install shapely pyproj pyshp
```

## 사용법

데이터 파일을 읽는 스크립트는 저장소 밖의 깨끗한 작업 디렉터리에서, 스크립트는 절대 경로로 실행한다.

```
python3 /절대경로/script/regions/build_kr_regions.py \
  --codes 법정동코드.csv --out kr_regions.csv \
  [--sig 시군구.shp] [--emd 읍면동.shp] [--li 리.shp]
```

SHP 인자는 모두 선택이다. 없으면 계층만 출력하고 bbox는 전부 비운다. 요약(레벨별 행 수, 자체/파생/없음 bbox 수, 매칭 실패 SHP 코드 수)은 stderr로 나온다.

테스트: 저장소 루트에서 `python3 -m unittest discover -s script/regions -p "test_*.py"` (위 패키지 필요).

## 출력 CSV 계약

UTF-8(BOM 없음), 헤더 `code,parent_code,level,kind,name,south,west,north,east`, 레벨 → 코드 순 정렬. bbox 네 칸은 전부 비우거나 전부 채운다(십진 도, 소수 6자리, 남≤북, 서≤동).

- 레벨/종류: 1 `시도`, 2 `시군구`(일반구 포함), 3 `읍면동`, 4 `리`. 종류는 화면에 그대로 표시되는 한국어 이름이다.
- 상위 지역은 코드로만 구한다: 시군구 → 시도(앞 2자리+0), 읍면동 → 앞 5자리+0(시군구 또는 일반구), 리 → 앞 8자리+00.
- 시도 행이 없는 시군구 자리 코드(세종 3611000000)는 최상위(레벨 1, `시도`)이고 읍면동이 바로 붙는다.
- 이름은 전체 이름에서 상위 지역의 전체 이름을 뺀 값("수원시 장안구", "독도리"). 앞뒤 공백 제거.
- bbox: SHP 코드를 뒤로 0을 채워 10자리로 맞춰 연결(5/8/10자리 모두 대응, 매칭 실패는 개수만 로그). 조각이 여럿이면 가장 큰 조각(원본 투영 좌표계 면적)의 bbox만 쓴다(울릉군/독도 보호). 도형이 없는 지역은 깊은 레벨부터 하위 지역 bbox의 합집합을 쓴다(자식, 그리고 시 본체는 앞 4자리가 같은 일반구). 그래도 없으면 비워 두고 지도는 상위 지역 bbox를 쓴다.

## Rails 적재

```
bin/rails "regions:import[/경로/kr_regions.csv]"
```

새 코드만 추가하고(insert-only) 기존 코드는 고치지 않으며, 원본과 다른 필드는 차이로만 보고한다. 개발 DB를 건드리지 않으려면 `DATABASE_URL=sqlite3:<임시 경로>`로 임시 DB에서 먼저 확인한다.

## 검증 상태

**실제 법정동코드 CSV(2026-09-29판)**: 존재 20,560행 = 시도 15 + 세종 최상위 1 + 시군구 268 + 읍면동 5,067 + 리 15,209. 코드 유일, 모든 상위 코드 존재, 자식 레벨 > 부모 레벨, 이름 공백 없음.

**실제 VWorld SHP(`AL_D001_00_20261109`, SIG·EMD·LIO 세 파일, 2026-11-11 확인)** — 설계 문서 8절 1~3번의 답:
- 코드 길이: `A1`은 SIG 5자리, EMD 8자리, LIO 10자리이고, 뒤에 0을 채우면 법정동코드 10자리와 대응한다. SIG 코드는 전부 법정동코드에 있다.
- `.dbf` 인코딩은 cp949(`.cpg`에 949)이다. SIG의 이름(`A2`)에는 시도 이름이 붙어 있고(예: "전남광주통합특별시 목포시") EMD·LIO는 짧은 이름이다. bbox 연결에는 이름을 쓰지 않고 코드만 쓴다.
- 일반구는 **구 단위 도형만** 있다. 시 본체(수원시 등)는 SIG에 없어서 앞 4자리가 같은 구들의 합집합으로 만든다(파생 29개).
- 매칭 실패: 법정동코드 CSV(2026-09-29판)를 그대로 쓰면 SHP 코드 16개가 맞지 않았다. 대구 달성군 구지면이 2026-09-30에 구지읍(`2771026800`)으로 승격되어 SHP만 새 코드를 쓰기 때문이다(읍면동 1 + 리 15). 구지면 계열 16행(`27710380xx`)을 구지읍 계열(`27710268xx`, 이름은 면 → 읍)로 바꾼 CSV로 돌리면 **매칭 실패가 0**이 된다. 코드 앞 8자리만 바뀌고 이름과 개수는 같다. 이름으로 맞추지 않고 코드를 맞춘다. 법정동코드 CSV의 새 판이 나오면 이 보정은 필요 없다.
- 결과(구지읍 반영 후): 20,560행 중 자체 bbox 20,484 / 파생 29 / 없음 47(모두 리). 없는 곳은 지도가 가장 가까운 상위 지역의 bbox를 쓴다. 주로 연천군 백학면, 제주시 애월읍, 철원군 원남면 일대의 리다(SHP에 해당 리 도형이 없다).
- 자식 bbox가 부모 bbox 밖으로 나가는 경우가 215건이다(섬 지역: 부모는 가장 큰 조각만 쓰는 규칙의 결과). 오류가 아니라 설계된 동작이다.
- 울릉군 bbox는 독도를 제외한 본섬(37.45~37.55, 130.79~130.92)이다.
- 실행 시간 약 10초(SIG·EMD·LIO 전체). 임시 DB 적재 후 재적재는 전부 "변경 없음"이다.

이 스크립트는 SHP 파일 이름의 레이어 약어를 보지 않으므로 `--li`에 LIO 파일을 넘기면 된다.
